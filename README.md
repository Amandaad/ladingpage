# 💄 Sistema Studio Amanda Simplício

Sistema de **Landing Page com Agendamento Inteligente**, desenvolvido para o Studio Amanda Simplício, com foco em **organização de horários**, **experiência do cliente** e **automação de agendamentos**.

---

## 📌 Visão Geral

O sistema permite que clientes realizem agendamentos online de forma simples e rápida, com integração direta ao **Google Agenda** e **WhatsApp**, evitando conflitos de horários e facilitando o controle do atendimento.

---

## 🚀 Funcionalidades

- 📅 Agendamento online
- ⏱ Tempo automático por serviço
- 🔒 Bloqueio de horários já ocupados
- 📆 Agenda visual no site
- 🔗 Integração com Google Agenda
- 📲 Confirmação automática via WhatsApp
- 📱 Interface responsiva (mobile e desktop)

---

## 🛠 Tecnologias Utilizadas

- HTML5  
- CSS3  
- JavaScript  
- Google Calendar (via link dinâmico)  
- WhatsApp API (link direto)

---

## 🧠 Funcionamento do Sistema

1. Cliente seleciona o serviço
2. Sistema calcula automaticamente o tempo de atendimento
3. Verifica se o horário está disponível
4. Exibe horários ocupados
5. Abre:
   - 📅 Google Agenda com evento preenchido
   - 📲 WhatsApp com mensagem automática
